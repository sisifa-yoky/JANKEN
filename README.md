# JANKEN CLUB

## ① 課題名

JANKEN CLUB

## ② 課題内容

JANKEN CLUBは、コンピューターと対戦できるレトロなアーケード風のじゃんけんゲームです。

プレイヤーがグー・チョキ・パーの中から好きな手を選ぶと、コンピューターがランダムに手を出し、その結果によって勝ち・負け・あいこが決まります。

また、スコアや連勝数、自己ベストを記録したり、効果音のON・OFFを切り替えたりできるようにしました。

## ⑤ 工夫した点・こだわった点

今回、特に工夫したのは、じゃんけんの勝敗判定やスコアを管理する部分です。

- **勝敗の判定：** `if` 文やオブジェクトを使い、プレイヤーとコンピューターの手を比較して勝ち・負け・あいこを判定できるようにしました。

- **ボタンの操作：** `addEventListener("click", function() {})` を使い、ボタンをクリックするとゲームが動くようにしました。また、キーボードからも手を選べるようにしました。

- **結果の表示：** `innerHTML` と `textContent` を使い、選んだ手の画像や勝敗のメッセージ、スコアが表示されるようにしました。

- **記録の保存：** `localStorage` を使い、自己ベストや連勝記録がブラウザに保存されるようにしました。

- **ゲームの演出：** 効果音やアニメーションを追加し、勝敗によって画面の見た目やメッセージが変わるようにしました。

今回の制作では、コードの作成や修正、機能の実装などで主にAIを活用しました。AIにコードを提案してもらいながら、実際に動かして確認し、必要に応じて修正を重ねていきました。

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

一番難しかったのは、勝敗によってスコアや連勝数を変化させたり、自己ベストを保存したりする部分でした。

特に、複数の変数や関数がどのようにつながって動いているのかを理解することが大変でした。

また、ボタンを連続して押したときにゲームの処理が重ならないようにしたり、効果音やアニメーションを結果に合わせて動かしたりする部分にも苦労しました。

次回は、コンピューターの難易度を選べる機能や、過去の対戦履歴を確認できる機能なども追加してみたいです。
